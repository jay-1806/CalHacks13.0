# Quicky.AI native icons

**Master (untouched):** repository root `Quicky Logo.png` (2048×2048 RGBA).

**Derived assets in this folder (do not treat as editable vectors):**

| File | Purpose |
|------|---------|
| `icon.png` | Electron / electron-builder default (1024, Frosted Pearl backed) |
| `icon-1024.png` | Transparent reframed 1024 master crop |
| `icon-1024-pearl.png` | Pearl-backed 1024 |
| `icon.icns` | macOS app / Dock icon |
| `icon.ico` | Windows app icon |
| `icon.iconset/` | Source set for `iconutil` |
| `qa-*.png` | Visual QA samples at common sizes |

Pearl backing is only for small-size Dock/taskbar legibility. The master PNG remains transparent and unmodified.
